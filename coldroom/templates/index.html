Learning panel

A beginner teaching model — not production-secure, not a pentest qualification. Checkboxes are not saved.

  1. Read the disclaimer at the bottom and the mode badge. This app listens only on http://127.0.0.1:5000 (this computer only).
  2. Open /api/status. Find the mode, the limits, the requested setpoint and the measured temperature.
  3. With --demo-insecure, run this one request from the project folder (in Windows PowerShell type curl.exe): 
    {{ example_command }}
  4. The setpoint jumps at once; the measured temperature moves gradually. Watch the chart and the alarm.
  5. Stop the app (Ctrl+C) and start it without --demo-insecure. The mode cannot be switched from the browser.
  6. Repeat the same request. Expect HTTP 401.
  7. Paste the terminal token into the operator panel, click Use token, apply -20.
  8. With the token, apply -10. Expect HTTP 422 out_of_policy.
  9. Authentication, authorization, validation, safety limits
    Authentication
    Who is calling? Here: a valid operator token.
    Authorization
    Is this caller allowed to do this action? Insecure mode skips this check on purpose.
    Input validation
    Is the request well-formed: JSON, a finite number, inside the global range?
    Operational safety limit
    Is the value acceptable to operate with? A policy applied even to authenticated users.
